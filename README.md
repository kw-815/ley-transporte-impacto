# Reforma a la Ley de Tránsito · Impacto Empresarial

Sitio de resumen ejecutivo del impacto, para el sector privado, de la Ley
Orgánica Reformatoria a la Ley Orgánica de Transporte Terrestre, Tránsito y
Seguridad Vial (LOTTTSV).

## Estructura

```
sitio-impacto-empresarial/
├── index.html              # Home (7 secciones + 6 categorías de impacto)
├── 404.html
├── css/styles.css          # Estilos (base heredada de ace2040 + adiciones propias)
├── img/logo-keyword-white.svg
└── pages/                  # Una página por categoría de impacto
    ├── categoria-a.html    # Nuevas cargas económicas
    ├── categoria-b.html    # Registro, tecnología y trazabilidad
    ├── categoria-c.html    # Riesgo sancionatorio y debido proceso
    ├── categoria-d.html    # Mercado y competencia
    ├── categoria-e.html    # Nuevas categorías reguladas
    └── categoria-f.html    # Seguros y responsabilidad civil
```

## Contenido

Cada categoría trae su comparativa completa "antes / con la reforma", con
severidad, a quién afecta y plazo de implementación, verificada artículo por
artículo contra los textos vigentes de la LOTTTSV, el COOTAD, el COIP, el
Código Orgánico del Ambiente y la Ley de Eficiencia Energética.

## Publicación

GitHub Pages sirve el sitio desde la raíz de la rama `main`.
